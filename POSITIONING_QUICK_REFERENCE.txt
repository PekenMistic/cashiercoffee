BORDER RADIUS:

TEXT SIZES:

SECTION 4: USER JOURNEY POSITIONING
═══════════════════════════════════════════════════════════════════════════════

1. USER LANDS ON PAGE
   └─ Sees header (sticky) with search
   └─ Filter bar below header (sticky)
   └─ Menu grid scrollable
   └─ No floating button (cart empty)

2. USER ADDS ITEM
   └─ Quantity badge appears on card
   └─ Floating button appears at bottom (fixed, z-40)
   └─ "Pop" animation (scale-105) when item added

3. USER CLICKS ITEM
   └─ Modal opens (from bottom on mobile, centered on tablet+)
   └─ Full customization options visible
   └─ Fixed padding ensures readability
   └─ "Add to Cart" button at bottom of modal

4. USER CLICKS FLOATING BUTTON
   └─ Cart modal opens (z-50, behind fixed button)
   └─ List of items, quantities, prices
   └─ Summary section (sticky at bottom)
   └─ "Checkout" button triggers confirmation

5. USER CLICKS CHECKOUT
   └─ Checkout modal opens (z-50, full overlay)
   └─ Order summary, payment methods
   └─ Success screen after confirmation
   └─ Auto-closes, returns to menu (cart cleared)

SECTION 6: RESPONSIVE BEHAVIOR RULES
═══════════════════════════════════════════════════════════════════════════════

RULE 1: Mobile First Always
────────────────────────────
- Default styles: mobile (no prefix)
- Tablet+: sm: prefix (640px+)
- Desktop: lg: prefix (1024px+)

RULE 2: Padding Increases on Larger Screens
─────────────────────────────────────────────
- Mobile: px-4 (16px)
- Tablet+: sm:px-6 (24px) in some places
- Maintains visual breathing room

RULE 3: Max-Width Content Constraint
─────────────────────────────────────
- All content: max-w-2xl (512px)
- Centered with mx-auto
- Prevents awkward wide layouts

RULE 4: Sticky Positioning Order
─────────────────────────────────
- Header: z-30, top-0
- Filter: z-20, top-[120px] (mobile) / top-[140px] (tablet+)
- Floating cart: z-40, bottom-6
- Modals: z-50 (above all)

RULE 5: Modal Responsiveness
────────────────────────────
- Mobile: items-end (slide from bottom)
- Tablet+: sm:items-center (centered)
- Width: w-full (mobile) → sm:max-w-md (tablet+)

RULE 6: Horizontal Scrolling Rules
──────────────────────────────────
- ALLOWED: Filter bar (overflow-x-auto)
- BLOCKED: Menu grid, content areas
- Scrollbar hidden with scrollbar-hide

RULE 7: Button & Input Sizing
─────────────────────────────
- All interactive elements: 44px+ height minimum
- Consistent padding: py-3 for most buttons
- Consistent rounding: rounded-lg for most components

RULE 8: Typography Scaling
─────────────────────────────
- Mobile fonts: 14px body, 30px titles
- Tablet+ fonts: Same size (no change needed)
- Emoji: 60px cards, 84px modals

RULE 9: Spacing Consistency
──────────────────────────────
- Horizontal: px-4 (mobile) consistent everywhere
- Vertical: py-4 mobile, py-6 tablet+ for sections
- Gap: gap-4 mobile, gap-6 tablet+

RULE 10: Animation & Transitions
─────────────────────────────────
- Modals: 300ms slide/fade
- Buttons: 200ms hover effect
- Cards: 200ms hover shadow/translate
- Pop animation: 300ms when item added


SECTION 7: COMMON RESPONSIVE FIXES
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Text too small on mobile
FIX: Use text-sm (14px) minimum for body, text-base (16px) for inputs

PROBLEM: Button not clickable on mobile
FIX: Ensure py-3 (28px) + padding = 44px+ total height

PROBLEM: Modal extends beyond screen
FIX: Use max-h-[90vh] for max height, overflow-y-auto for scroll

PROBLEM: Content too wide on tablet
FIX: Use max-w-2xl (512px) centered with mx-auto

PROBLEM: Filter bar scrolls too much
FIX: whitespace-nowrap on buttons, overflow-x-auto on container

PROBLEM: Cards not equal width on mobile
FIX: Use grid-cols-2 (always 2 columns), gap-4 for spacing

PROBLEM: Floating button covered by content
FIX: Use h-24 padding below content, z-40 for button

PROBLEM: Modal hard to dismiss on mobile
FIX: Large close button (p-2 = 44px+), swipe support

PROBLEM: Touch targets too small
FIX: Minimum 44x44px, use p-2/p-3 for padding

PROBLEM: Padding inconsistent between sections
FIX: Stick to p-4 (mobile) / p-6 (tablet+) pattern
