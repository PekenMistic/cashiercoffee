📞 SUPPORT & TROUBLESHOOTING

  Common Issues:
    
    Menu Won't Load?
    → Check /api/public/menu endpoint
    → Verify DATABASE_URL is set
    → Check browser console for errors
    
    Orders Not Saving?
    → Check /api/public/orders POST works
    → Verify database write permissions
    → Check order payload structure
    
    QR Code Won't Scan?
    → Verify adequate contrast in code
    → Check code isn't damaged/dirty
    → Test with multiple phones
    → Try different QR scanning apps
    
    Responsive Design Issues?
    → Clear browser cache (Ctrl+Shift+Del)
    → Check for conflicting CSS
    → Test in different browsers
    → Verify Tailwind CSS is loaded
